# VTT to LRC

`vtt` フォルダ内のWebVTT字幕ファイルを読み込み、LRC形式の歌詞を標準出力へ出力するプログラムです。

## 必要環境

- Python 3.14以上
- 外部パッケージ不要

## 使い方

1. 変換したい `.vtt` ファイルをプロジェクト内の `vtt` フォルダに置きます。
2. プロジェクトのルートで次を実行します。

```sh
python main.py
```

変換結果は標準出力に表示されます。ファイルへ保存する場合は、出力をリダイレクトしてください。

```sh
python main.py > output.lrc
```

## 変換例

入力:

```vtt
00:00:23.100 --> 00:00:29.500
予測不可の純情　矛盾さえも真実
```

出力:

```text
[00:23.10] 予測不可の純情 矛盾さえも真実
```

タイムスタンプは開始時刻を使い、ミリ秒を1/100秒に切り捨てます。歌詞内の連続した空白は半角スペース1つにまとめます。

色などのWebVTTタグとHTMLエンティティ、ゼロ幅文字を取り除き、重複した字幕フレームをまとめます。連続した短い字幕は一行に統合し、同じ短い語が8回を超えて繰り返される場合は、8回と省略記号で出力します。短い無字幕区間は、直前の字幕が終わる時刻に空の行として出力します。

タイトル（`line:0%`）や「作詞」「作曲」「編曲」「歌唱」のクレジット字幕は出力しません。

## 複数ファイル

`vtt` フォルダ直下にある `.vtt` ファイルをファイル名順に変換し、結果を続けて出力します。対象ファイルがない場合はエラーメッセージを標準エラーへ出し、終了コード `1` で終了します。
